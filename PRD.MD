# PROMPT PEMBUATAN LANDING PAGE CRM CATERBOX + PRD V1, V2, V3

## Role

Bertindak sebagai **Senior Product Manager**, **Product Owner**, **Business Analyst**, **CRM Consultant**, **UI/UX Designer**, dan **Frontend Architect**.

Buat dokumen profesional yang berisi evolusi **Product Requirement Document (PRD)** mulai dari versi awal hingga versi lengkap untuk **Landing Page CaterBox CRM**.

Landing Page harus mengikuti standar **Modern SaaS Landing Page** dan sesuai dengan sistem **CRM Catering** yang dibangun menggunakan React.

---

# INFORMASI PROJECT

## Nama Project

**CaterBox CRM**

## Jenis Sistem

Customer Relationship Management (CRM) untuk usaha Catering yang membantu mengelola pelanggan, pemesanan, transaksi, membership, promosi, dan analisis bisnis.

## Teknologi

* React
* Vite
* Tailwind CSS
* Supabase
* React Hooks
* Shadcn UI
* Recharts

# TUJUAN LANDING PAGE

Landing Page digunakan untuk:

* Memperkenalkan CaterBox CRM
* Menarik calon pelanggan
* Menjelaskan fitur CRM
* Meningkatkan trial registration
* Meningkatkan demo booking
* Meningkatkan customer acquisition
* Meningkatkan loyalitas pelanggan

Landing Page harus mengikuti:

* AIDA Framework
* Conversion-Oriented Design
* Modern SaaS Design
* Mobile First
* Responsive Design

# TENTANG CATERBOX CRM

CaterBox CRM merupakan sistem Customer Relationship Management yang membantu usaha catering dalam mengelola pelanggan, pemesanan catering, transaksi pembayaran, membership pelanggan, campaign promosi, feedback pelanggan, serta dashboard analitik untuk meningkatkan kualitas pelayanan dan loyalitas customer.
